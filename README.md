# Brain Atlas · 뇌의 구조와 연결

한국어 설명과 영문 명칭을 함께 제공하는 교육용 3D 뇌 해부도입니다. 별도 계정, 로그인, API 키 없이 브라우저에서 실행됩니다.

**웹에서 사용:** [Brain Atlas 열기](https://honggi82-brain-atlas.honggi82.chatgpt.site). 설치하거나 개인 컴퓨터에서 서버를 실행할 필요가 없습니다. GitHub 소스 저장소는 비공개로 유지합니다.

상단의 **Kr / En**으로 화면과 기능 설명의 언어를 선택합니다. Kr에서는 `해마 (Hippocampus)`처럼 영어를 괄호로 병기합니다. 단순 직역 대신 해부학 명칭을 사용하며, `중심전회` 같은 임상 동의어로도 검색할 수 있습니다. [용어 표기 기준](public/TERMINOLOGY.md)을 참고하세요.

이번 개선본은 **원본 HCP streamline을 이용한 섬유 추적 보기**와 **표시 제어를 통합한 왼쪽 계층형 목록**을 제공합니다. 이전 검토본은 이 컴퓨터의 `../brain-atlas` 폴더에 그대로 보존되어 있습니다. 개선본은 `brain-atlas-v2/Start.cmd`로 실행하세요.

## 실행

이 컴퓨터에서는 `Start.cmd`를 더블클릭하세요. 브라우저에서 **http://127.0.0.1:4173/** 가 열립니다. 실행 창에서 `Ctrl+C`를 누르면 종료됩니다. 이 주소는 현재 컴퓨터에서만 접속할 수 있습니다.

새 컴퓨터에는 Node.js 22.13 이상과 Python 3이 필요합니다. 터미널에서는 아래 순서로 실행할 수 있습니다.

```sh
npm ci
npm run build
python scripts/serve.py --open
```

개발 중에는 `npm run dev`, 기존 빌드 확인에는 `npm run preview`를 사용합니다. 모델·연결표·압축 해제기는 저장소에 포함되어 있어 일반 실행에 외부 데이터 다운로드가 필요하지 않습니다.

## 탐색 방법

- **해부학**: 뇌를 드래그해 회전하고 휠로 확대합니다. 형상이나 목록을 선택하면 이름과 역할을 읽을 수 있습니다.
- **뇌엽**: 3D 화면 위의 색상 범례에서 전두엽·두정엽·측두엽·후두엽·섬엽·변연엽을 선택하면 이름, 위치·경계, 주요 기능이 표시됩니다. 왼쪽 `대뇌피질` 아래에서 뇌엽 전체나 하위 구조를 표시·숨기고, 오른쪽에서 `단독 보기`와 `가까이`를 사용할 수 있습니다. `이마엽`, `마루엽` 등의 이전 표기로도 검색합니다. 구조를 직접 선택하면 소속 뇌엽도 함께 표시됩니다.
- **뇌엽 분류의 범위**: 원본의 피질 분류를 보존했습니다. 특정 뇌엽으로 분류되지 않은 고랑은 `뇌엽 경계·기타 고랑`에 표시합니다. 섬엽은 주변 구조를 포함한 복합 형상이며, 변연엽은 원본 분류의 일부 구조만 포함합니다. 각 설명에서 이 한계를 확인할 수 있습니다. 뇌엽 색상 범례는 해부학 모드에만 나타나며 섬유 방향의 RGB 색상과 구분됩니다.
- **통합 구조 목록**: 왼쪽 분류의 펼침 버튼으로 하위 구조를 확인합니다. 체크박스는 분류 전체 또는 해당 구조의 표시를 제어하고, 이름은 구조를 선택해 오른쪽에 설명을 보여줍니다. 오른쪽의 중복 LAYERS 목록은 제거했습니다. 분류가 꺼져 있을 때 하위 구조 하나를 선택하면 그 구조만 켜집니다.
- **검색**: 한국어, 영어, 기능으로 검색합니다. `/` 키로 검색창에 이동합니다.
- **내부 구조**: 피질 투명도를 높이거나, 구조를 선택한 뒤 `단독 보기`를 누릅니다. 좌뇌·우뇌와 8개 구조 계층도 선택할 수 있습니다.
- **Connectome**: 백질 신경로를 선택하고 HCP-MMP 피질 영역별 겹침 확률을 탐색합니다. 영역 ID를 누르면 그 영역과 연결되는 다른 신경로를 확인할 수 있습니다.
- **섬유 추적**: HCP1065 원자료의 68개 다발을 탐색합니다. 뇌량·활꼴다발·피질척수로·시각방사 등의 가는 궤적과 퍼지는 형태를 볼 수 있습니다. 표시 밀도, 주변 경로, 단독 보기, 전체 섬유 보기를 선택할 수 있습니다. 빨강·초록·파랑은 각각 좌우·앞뒤·위아래 방향입니다.
- **경로 표현 전환**: Connectome의 `섬유 추적 / 해부 모형`으로 원래 영상 좌표의 궤적과 기존 해부 그림을 전환합니다. 두 좌표계를 임의로 겹치지 않습니다.
- **확률 필터**: 0%로 내리면 원본의 0도 표시합니다. 검색·필터는 원자료를 변경하지 않습니다.

## 포함된 자료

| 항목 | 범위 |
| --- | --- |
| 해부 구조 | 좌우·세부 조각을 포함한 325개 선택 단위, 서로 다른 영문 명칭 174개 |
| 대뇌피질 | 이랑·고랑, 해마·해마곁이랑 등 128개 형상 |
| 깊은 구조 | 기저핵·편도체 23개, 간뇌 41개, 백질·교련 9개 |
| 뇌간·소뇌·뇌실 | 각각 32개·31개·7개 |
| 백질 경로 형상 | HCP1065 유래 54개 근사 형상 |
| 정밀 섬유 보기 | 68개 다발, 원본에서 고른 98,484개 궤적, 다발당 최대 2,000개 |
| 연결 확률 표 | HCP-MMP 180개 영역 × 좌우 신경로 52개 열 = 9,360개 값 |
| 연결표와 정밀 궤적 대응 | 48개 열; PTAT·C_R은 양쪽 모두 미대응으로 유지 |
| 연결표와 해부 모형 대응 | HCP 유래 형상 36개 열 + 별도 Z-Anatomy 뇌궁 2개 열; 나머지 14개 열은 이 보기에서 표 전용 |

325개는 고유한 기능 영역의 수가 아닙니다. 하나의 선택 단위가 여러 그래픽 조각으로 구성될 수 있습니다. 원본 모델의 좌우·정중선 표기를 보존했으며 모든 구조에 좌우 한 쌍이 있는 것은 아닙니다.

## 해석의 한계

이 앱은 학습용 해부도입니다. 한국어·영어 기능 요약은 여러 기능 중 대표적인 역할을 설명하며, 전문가의 교육 내용 검수는 아직 받지 않았습니다.

해부 모형의 추가 핵과 단일 관 신경로는 약 7 mm 정합 오차가 보고된 교육용 근사 형상입니다. 새 섬유 보기에서는 HCP 원래 영상 좌표의 궤적을 사용하지만, 집단 평균의 표시용 표본이며 개인의 DTI 검사나 축삭·시냅스를 직접 측정한 결과가 아닙니다. 색은 섬유의 축 방향이며 신호 방향·연결 강도·FA를 뜻하지 않습니다. 임상·수술 용도로 사용할 수 없습니다. [변환 방법과 한계](public/TRACTOGRAPHY.md)를 참고하세요.

Connectome의 값은 **신경로 마스크와 영역이 겹친 피험자 비율**입니다. 축삭 수, 정보 흐름의 방향, 영역 간 연결 강도, 기능적 상관을 의미하지 않습니다. 일부 신경로는 표본 수가 다르므로 확률을 1,065명 기준의 인원수로 환산하지 않습니다. HCP-MMP 기능 구획을 해부 모델의 이랑과 임의로 일치시키지 않습니다. 원본 약어 PTAT/TPAT, C_R/C_PR 차이도 보존했습니다.

## 원자료와 재현

- 형상: [Brain Project](https://github.com/itayinbarr/brainproject), 고정 리비전 `2929e94f521a8ddceab26bc100a98dc06b0da060`.
- 연결표: [Yeh 2022 HCP1065 배포 페이지](https://brain.labsolver.org/hcp_trk_atlas.html), [논문](https://www.nature.com/articles/s41467-022-32595-4).
- 최초 참조: [Human Atlas](https://github.com/ashemag/human-atlas), 선택 제스처 처리 코드를 MIT 조건에 따라 수정했습니다.
- 원본 XLSX와 추출 JSON은 `public/data/`에 있습니다. 모델의 고정 해시는 `asset-lock.json`, 표의 해시와 추출 방법·대응 기준은 JSON의 `provenance`, `modelMapping`에 있습니다.
- `node scripts/prepare.mjs`는 현재 명칭·설명으로 `parts.json`을 재생성합니다. `verify-matrix.py`는 Excel을 실행하지 않고 XML의 캐시된 수치 9,360개를 모두 대조합니다.

모델과 파생 메타데이터, 연결 자료의 재배포 조건은 [저작권·출처 안내](public/ATTRIBUTION.md)를 확인하세요.

## 공개 배포

2026-09-09 소유자의 요청으로 Sites에 공개 배포했습니다. 웹사이트는 주소를 아는 누구나 로그인 없이 사용할 수 있고, GitHub 저장소는 비공개입니다. `.openai/hosting.json`의 기존 프로젝트를 재사용하며, 검증한 소스와 정적 빌드 결과를 함께 배포합니다. 공개 링크: https://honggi82-brain-atlas.honggi82.chatgpt.site

일반 정적 호스팅에서 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. 별도 백엔드·데이터베이스·비밀키가 필요하지 않습니다. Draco `.wasm` 파일을 `application/wasm`으로 제공해야 합니다. `index.html`의 `noindex`는 검색 노출 억제 요청일 뿐, 접근 제한이나 비공개 보장을 제공하지 않습니다.

섬유 자료의 `.bin.gz`는 압축된 파일 자체를 전달하며 앱이 해시 검증 후 압축을 풉니다. 파일을 미리 압축 해제하거나 원래 압축을 HTTP `Content-Encoding`으로 지정하지 마세요. HTTPS 또는 localhost와 `DecompressionStream`을 지원하는 최신 브라우저가 필요합니다. 초기 전체 개요는 약 634 KB이며 선택한 다발의 정밀 자료를 추가로 불러옵니다.
